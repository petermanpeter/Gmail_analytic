# Gmail_analytic
Analyze Gmail summary for insight

# Steps
1) Install dependencies in your terminal: 
pip install -r requirements.txt

2) Start the server: 
streamlit run app.py

3) Access the App: Codespaces will automatically detect that Streamlit is running on Port 8501. A small popup will appear in the bottom right corner of VS Code saying "Your application running on port 8501 is available."

4) Open in Browser: Click "Open in Browser" on that popup. Your Streamlit app will load, ready for use!

# Deploy by commit
git add .
git commit -m "Your commit message here"
